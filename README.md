# Event-Management-OOP
## About The Project

**Event Management System** is a Java console application designed for event scheduling, user management, and ticket processing. Built using Core Java and the Java Collection Framework (JCF), it features role-based access control, persistent text-file storage, and a priority queue system.

### Key Features
* **Role-Based Access Control**: Separate user and administrator workflows.
* **Polymorphic Events**: Specialized behavior for Concerts, Conferences, and Sports Matches.
* **Priority Request Handling**: Automatic processing of ticket refund requests ahead of purchase requests.
* **File Persistence**: Load and save system state seamlessly using formatted `.txt` files.
